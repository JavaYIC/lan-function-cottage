# 澜的函数小屋

面向安徽 2027 高考备考的平板函数专题学习站。React + Vite 静态应用，学习记录保存在访问者浏览器的 localStorage，不需要业务后端或模型 API。

## 已实现

- 可点击的知识地图与先修方向，8 个微知识点。
- 12 题诊断（从题库选取）、每知识点简单/中等/难各 3 题，共 72 道原创单选题。
- 每知识点 9 道不同题均独立答对后，知识地图点亮掌握标志；提示、不确定和跳过不计通过。
- 三级提示、逐步解析、错因自选、暂停续做。
- 二次函数、指数函数、对数函数支持伸缩、翻转、平移和数字输入；支持给 x 求 y、给 y 反查全部交点、自由拖动 (x,y)、缩放平移、原函数对照和零点预测。
- 错题回访、隔天复测、阅读与答题记录。
- JSON 备份导出与合并导入；同 ID 冲突优先保留本机记录。
- 真实进度环、知识地图路径高亮、分段导航与一次性答题反馈动效；全站支持系统减少动态效果设置。
- 简单访问密码入口、7 天记住登录、本次会话登录与主动锁定；锁定不删除学习记录。

所有题目均标明原创；尚未收录历年真题和模拟题。难题含部分复合、分段及指数对数综合，完整进阶专题仍待扩展。2027 具体卷别以当年官方安排为准。

## 运行

需要 Node.js 22.12+（本次使用 24.14）。

```powershell
npm install
npm run dev
npm run check
npm run build
```

本地预览地址为 `http://127.0.0.1:5178/`；生产输出在 `dist/`，可由静态托管服务提供。路由使用 hash，不依赖服务器重写。

## 维护

- `src/data/topics.js`：微课程、例题、教材关联和来源链接。
- `src/data/questions.js` 与 `questions-extra.js`：题干、选项、答案、提示、解析及题源。
- `src/lib/progress.js`：学习状态、回访计划、备份校验与合并。
- `src/lib/graph.js`：函数求值和实交点的解析求解；`scripts/graph.test.mjs` 覆盖定义域、反查、开口翻转、常函数及数值边界。
- `src/components/`：地图、课程、答题、图像与公式排版。
- `src/polish.css`：全站视觉与动效层；[DESIGN-REFERENCES.md](DESIGN-REFERENCES.md) 记录 CodePen 参考与独立实现范围。
- `scripts/check-content.mjs`：题目结构和 KaTeX 严格解析检查。
- `scripts/progress.test.mjs`：掌握状态、复测、备份与恢复回归检查。

新增题目时保持 id 稳定，避免已有记录失去对应题目；修改答案前重新核对数学与全部干扰选项。变式不能标成原题或高考真题。首次短测只给初步线索，状态不宣称统计意义上的掌握概率。

## 验收记录

题库包含 8 个微知识点、72 道题；内容结构与全部公式通过严格解析，13 项进度回归测试通过。内置浏览器实测短测到结果、练习提示与刷新恢复、错因保存、教材例题展开、图像参数及底数切换、备份下载和合并导入。新增九题掌握流程验证 8/9 不点亮、9/9 点亮及刷新保留。

视觉稿由内置 imagegen 生成；已对照首屏布局、白底与浅绿配色、文字层级、地图节点、触控按钮和响应式折行。成品课程标题及例题使用数学复核后的真实数据，暂停与诊断后的状态随本机记录变化；这些动态内容与概念稿示例不同。图标为可缩放的代码图标，数学曲线由 SVG 精确绘制。

## 隐私与使用

浏览器的本地进度不会自动上传，也不会跨设备同步。清理数据、更换浏览器或设备前，请导出备份；导入会合并记录，不删除已有答题历史。网站访问范围由托管平台单独管理。

当前访问密码是用户选择的浏览器端便利入口，托管平台仍为公开访问。源码只保存校验摘要，浏览器端实现可以绕过，不构成服务端身份认证或内容保护。访问状态单独存储在 `function-study:access:v1`，修改 `src/lib/access.js` 中的校验摘要会使旧登录状态失效。不要将其他账号的密码用于此入口。

## GitHub Pages 发布

项目包含独立的 Pages 构建，原有静态托管构建保持可用：

```powershell
npm run check
npm run build:pages
npm run preview:pages
```

`dist-pages/` 中的 HTML、脚本、样式、数学字体和站点图标全部使用相对路径，可用于仓库子路径。GitHub 仓库默认分支使用 `main`，在 Settings → Pages 中将 Source 设为 GitHub Actions；`.github/workflows/pages.yml` 会检查题库和学习逻辑、构建并发布。自动发布使用 GitHub 提供的短期权限，不需要填写个人 token。

迁移至其他域名不会自动迁移浏览器进度。先在原网站导出 JSON 备份，再在新网站导入。网站密码入口与 7 天记住登录功能保持一致，但每个域名分别保存登录状态。

国内网络访问能力需要在使用者的实际网络中验证，发布成功不等于所有地区均可访问。
